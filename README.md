# 📍 Гео-трансляция в реальном времени

Бесплатный open-source проект для передачи своего местоположения другому человеку по ссылке в реальном времени.

**Стек:** HTML + CSS + JS (без сборки) • Leaflet + OpenStreetMap • Supabase Realtime (бесплатный тариф)

---

## 🎯 Возможности

| Функция | Описание |
|---------|----------|
| 🔴 **Трансляция** | Кнопка «Начать» → доступ к GPS → генерация 6-символьного кода |
| 🔗 **Шаринг** | Ссылка вида `https://ваш-сайт.com/live.html?id=ABC123` |
| 🗺️ **Карта** | Leaflet + OSM (бесплатно, без API ключей), маркер движется в реальном времени |
| 📊 **Инфо** | Точность (радиус), время обновления, статус онлайн/офлайн |
| 🎯 **Центрирование** | Кнопка «Центрировать на маркере» для зрителя |
| 💾 **Автовосстановление** | Сессия сохраняется в localStorage, переживает перезагрузку вкладки |

## 🚀 Быстрый старт (5 минут)

### 1. Создайте проект в Supabase

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project** → войдите через GitHub
2. **New Project** → Organization: *ваш аккаунт* → Name: `geo-live` → Password: *любой* → Region: *ближайший* → **Create new project**
3. Подождите 1-2 минуты пока проект создастся

### 2. Настройте базу данных

1. В левом меню: **SQL Editor** → **New query**
2. Скопируйте содержимое файла `supabase-setup.sql` и вставьте
3. Нажмите **Run** (Ctrl+Enter) — должны появиться зеленые галочки `Success. No rows returned`

### 3. Включите Realtime

1. В левом меню: **Database** → **Replication** (вкладка)
2. Найдите таблицу `sessions` → переключите тумблер **Enabled** → **Save**
3. Статус должен стать зеленым «Enabled»

### 4. Получите ключи API

1. В левом меню: **Settings** (шестеренка) → **API**
2. Скопируйте:
   - **Project URL** (вида `https://xxxxx.supabase.co`)
   - **anon/public** key (длинный JWT, начинается с `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`)

### 5. Настройте сайт

Откройте `index.html` в браузере (через локальный сервер, см. ниже) → вставьте URL и Key → **«Сохранить настройки»** → **«Начать трансляцию»**

## 🌐 Развертывание на бесплатном хостинге

### Вариант А: GitHub Pages (рекомендую)

1. Создайте репозиторий на GitHub (Public)
2. Загрузите все файлы проекта (`index.html`, `live.html`, `app.js`, `viewer.js`, `style.css`)
3. В репозитории: **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: `main` / `root` → **Save**
4. Через 1-2 минуты сайт будет доступен по адресу `https://ваш-ник.github.io/имя-репо/`

> ✅ **HTTPS включен автоматически** — геолокация будет работать на телефоне!

### Вариант Б: Vercel

1. Зайдите на [vercel.com](https://vercel.com) → **Add New Project** → Import Git Repository
2. Выберите репозиторий → **Deploy** (настройки по умолчанию)
3. Готово: `https://имя-проекта.vercel.app`

### Вариант В: Netlify

1. Зайдите на [netlify.com](https://netlify.com) → **Add new site** → **Deploy manually**
2. Перетащите папку проекта в зону загрузки
3. Готово: `https://случайное-имя.netlify.app`

> **Все три хостинга дают бесплатный SSL (HTTPS), кастомные домены, и не требуют карты.**

## 📱 Как пользоваться (пошагово)

### Транслятор (владелец геолокации)

1. Откройте `https://ваш-сайт.com/` на телефоне
2. Введите Supabase URL и Key (один раз, запоминаются в браузере)
3. Нажмите **«Начать трансляцию»**
4. Разрешите доступ к геолокации (браузер спросит)
5. Нажмите **«Копировать»** ссылку
6. Отправьте ссылку в любой мессенджер
7. Когда закончите — **«Остановить трансляцию»**

### Зритель (получатель ссылки)

1. Открывает ссылку на любом устройстве (телефон, ПК, планшет)
2. Видит карту с вашим маркером, движущимся в реальном времени
3. Может нажать **«Центрировать на маркере»**
4. Видит точность, время последнего обновления, статус

## ⚙️ Технические детали

### Протокол данных (Supabase таблица `sessions`)

```sql
id          TEXT PK        -- "A1B2C3" (6 символов)
created_at  TIMESTAMPTZ    -- когда началась
updated_at  TIMESTAMPTZ    -- последнее обновление координат
is_active   BOOLEAN        -- true = трансляция идет
lat         DOUBLE PRECISION
lng         DOUBLE PRECISION
accuracy    DOUBLE PRECISION  -- метры (radius от GPS)
```

### Realtime события

Транслятор делает `UPDATE` каждые ~1-3 секунды (по мере прихода GPS-данных).
Зритель подписан на `postgres_changes` фильтр `id=eq.<sessionId>` — получает обновления за <100мс.

### Автовосстановление сессии

Если транслятор случайно закрыл вкладку или обновил страницу:
- `sessionId` сохранён в `localStorage` (24 часа)
- При повторном открытии `index.html` → проверка в БД → возобновление трансляции
- Ссылка для зрителей остаётся той же

## ⚠️ Известные ограничения

| Ограничение | Описание | Обходное решение |
|-------------|----------|------------------|
| **Геолокация в фоне на iOS** | Safari останавливает `watchPosition` когда вкладка неактивна | Держите вкладку открытой, не блокируйте экран; используйте «Добавить на главный экран» (PWA-like) |
| **Точность GPS в помещении** | 10-50 м (Wi-Fi/Cell triangulation) | Выходите на открытую территорию для лучшей точности |
| **HTTPS обязателен** | Geolocation API не работает на HTTP | Все бесплатные хостинги (GitHub Pages, Vercel, Netlify) дают HTTPS автоматически |
| **Лимит Realtime** | 2 млн сообщений/мес | Для 1 сессии 24/7 хватает на ~11 лет |
| **Публичный anon key** | Ключ виден в коде страницы | RLS политики ограничивают доступ только к активным сессиям; для продакшена добавьте авторизацию |
| **Нет истории трека** | Только текущая точка | Можно добавить таблицу `locations` с `session_id, lat, lng, accuracy, created_at` |

## 🔧 Настройка под себя

### Изменить длину кода сессии
В `app.js`: `generateSessionId()` → измените цикл `for (let i = 0; i < 6; i++)`

### Изменить частоту обновлений
В `app.js` → `watchPosition` options: `maximumAge: 0` (0 = максимально часто)
В Supabase клиент: `eventsPerSecond: 10` (макс. 10 обновлений/сек на канал)

### Добавить историю трека
1. Создайте таблицу `locations (session_id, lat, lng, accuracy, created_at)`
2. В `app.js` делайте `INSERT` вместо `UPDATE`
3. В `viewer.js` при первом заходе загружайте последние N точек и рисуйте `L.polyline`

### Свой дизайн маркера
В `viewer.js` → `createCustomMarker()` → измените SVG внутри `markerHtml`

## 🛡️ Безопасность и приватность

- **Сессия = 6 случайных символов** (36⁶ ≈ 2 млрд вариантов) — перебор невозможен
- **Данные только в памяти и Supabase** — никуда больше не уходят
- **RLS политики** — аноним может читать только `is_active = TRUE`
- **Автоочистка** — неактивные сессии можно удалять по крону (см. SQL комментарий)
- **Никаких логов, аналитики, куков** — только `localStorage` для удобства

## 🐛 Troubleshooting

| Проблема | Решение |
|----------|---------|
| «Геолокация не работает» | Откройте сайт по **HTTPS** (не `file://`, не `http://localhost` без TLS) |
| «Supabase connection failed» | Проверьте URL и Key; убедитесь, что проект не на паузе (Supabase pausaет бесплатные проекты после 7 дней неактивности — зайдите в дашборд раз в неделю) |
| «Сессия не найдена» | Проверьте ID в ссылке; убедитесь, что транслятор нажал «Начать» |
| «Маркер не двигается» | Откройте консоль (F12) → проверьте ошибки Realtime; убедитесь, что Replication включена для таблицы `sessions` |
| «Точность 1000+ метров» | GPS в помещении не работает хорошо; выйдите на улицу |
