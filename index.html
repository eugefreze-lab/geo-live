Как это работает

  • Нажмите «Начать трансляцию» — браузер запросит доступ к GPS
  • После получения координат появится ссылка — скопируйте и отправьте
  • Получитель откроет карту и увидит вас в реальном времени
  • Данные обновляются каждые 3 секунды через Supabase Realtime

Важно: Геолокация работает только на HTTPS или localhost. На GitHub Pages HTTPS включается автоматически.

Работает на Supabase Realtime + Leaflet + OpenStreetMap
